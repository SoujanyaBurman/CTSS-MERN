1. SUMMARY OF CODEBASE CHANGES MADE
================================================================================
The following production adjustments have already been implemented directly in your 
project so that you do not need to rewrite any logic:

1. Dynamic API Base URL (client/src/api/axiosInstance.js):
   - Changed hardcoded '/api' to: import.meta.env.VITE_API_URL || '/api'
   - This allows Netlify to talk to your live Render backend URL while still 
     working on localhost during local development.

2. Netlify Single Page Application (SPA) Routing Rewrite (client/public/_redirects):
   - Created client/public/_redirects with: /*    /index.html   200
   - Prevents 404 errors when a user reloads or navigates directly to subroutes 
     (e.g., /customer/dashboard or /admin/tickets).

3. Client Environment Reference (client/.env.example):
   - Added documentation showing: VITE_API_URL=https://your-backend.onrender.com/api

4. Server Port Binding (server/server.js):
   - Verified dynamic port binding: const PORT = process.env.PORT || 5000;
   - Render automatically supplies the PORT environment variable.

3. STEP 1: SET UP MONGODB CLOUD (MONGODB ATLAS)
================================================================================
1. Go to https://www.mongodb.com/cloud/atlas and sign in (or register).
2. Click "Create" or "Build a Database".
3. Select "M0 Shared" (Free tier):
   - Choose AWS or Google Cloud.
   - Choose the region nearest to you (e.g., Mumbai, Singapore, Frankfurt).
   - Click "Create Deployment".
4. Create a Database User:
   - Username: e.g., ctss_admin
   - Password: Click "Autogenerate" or choose a strong password (e.g. CtssCloudPass2026!)
   - Click "Create Database User" (Save the password!).
5. Network Access (IP Whitelist):
   - Under "Where would you like to connect from?", select "Allow Access from Anywhere".
   - IP Address: 0.0.0.0/0
   - (This is required because Render cloud servers use dynamic IP addresses).
6. Copy Connection String:
   - Click "Connect" on your cluster -> choose "Drivers" (Node.js).
   - Your string looks like:
     mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/?retryWrites=true&w=majority
   - Add the database name /ctss_db right before the ?:
     mongodb+srv://ctss_admin:CtssCloudPass2026!@cluster0.xxxxx.mongodb.net/ctss_db?retryWrites=true&w=majority

5. STEP 3: DEPLOY BACKEND ON RENDER
================================================================================
1. Log in to https://render.com.
2. Click "New +" -> "Web Service".
3. Select "Build and deploy from a Git repository" -> Connect your GitHub repo (CTSS-MERN).
4. Fill in the service configuration:
   - Name: ctss-backend
   - Region: Select closest region (e.g. Singapore, Frankfurt, Oregon)
   - Branch: main
   - Root Directory: server        <-- CRITICAL!
   - Runtime: Node
   - Build Command: npm install
   - Start Command: npm start
   - Instance Type: Free
5. Add Environment Variables (click "Add Environment Variable"):
   - NODE_ENV: production
   - MONGODB_URI: <your MongoDB Atlas connection string from Step 1>
   - JWT_SECRET: ctss_production_secure_token_secret_key_2026_xyz
   - CLIENT_URL: *
6. Click "Deploy Web Service".
7. Wait 2-3 minutes until Render status says "Live".
8. Copy your live backend URL from the top of the Render page:
   e.g., https://ctss-backend.onrender.com
9. Verify health check in your browser:
   https://ctss-backend.onrender.com/api/health
   Should return: {"status":"ok","timestamp":"..."}

================================================================================

   e.g., https://ctss-support-portal.netlify.app

8. TROUBLESHOOTING & PRO TIPS
================================================================================
- Render Free Tier Spin-down ("Cold Starts"):
  On the free tier, Render puts the server to sleep after 15 minutes of inactivity. 
  The very first request may take ~50 seconds to wake up. Subsequent requests will be 
  instantaneous (< 150ms). You can use a free service like UptimeRobot to ping 
  https://your-backend.onrender.com/api/health every 10 minutes to keep it awake!

- MongoDB Atlas IP Error (MongoServerSelectionError):
  Make sure you added 0.0.0.0/0 to MongoDB Atlas Network Access. Render does not have 
  a static IP on the free tier.

- VITE_API_URL Missing /api:
  Ensure your Netlify VITE_API_URL ends with /api (e.g., https://ctss-backend.onrender.com/api).
